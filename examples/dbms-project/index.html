What changed in v2

Starter schema (3NF)

This is a starting point for priya to refine, not the final design. PK = primary key, FK = foreign key. Use these exact snake_case names so the SQL and the app match. No derived columns are stored: the number of available copies is always calculated from loan.

category

  • category_id INT
  • name VARCHAR UNIQUE NOT NULL

publisher

  • publisher_id INT
  • name VARCHAR NOT NULL
  • city VARCHAR

author

  • author_id INT
  • name VARCHAR NOT NULL

book

  • book_id INT
  • isbn VARCHAR UNIQUE
  • title VARCHAR NOT NULL
  • category_id → category
  • publisher_id → publisher
  • pub_year INT
  • total_copies INT CHECK ≥ 0
  • available_copies removed in v2 (derived data)

book_author

  • book_id → book
  • author_id → author
  • Composite PK; resolves the M:N between book and author

member

  • member_id INT
  • name VARCHAR NOT NULL
  • email VARCHAR UNIQUE
  • phone VARCHAR
  • member_type ENUM('student','faculty')
  • joined_on DATE

staff

  • staff_id INT
  • name VARCHAR NOT NULL
  • email VARCHAR UNIQUE

loan

  • loan_id INT
  • book_id → book
  • member_id → member
  • staff_id → staff
  • issue_date DATE NOT NULL
  • due_date DATE NOT NULL, CHECK ≥ issue_date
  • return_date DATE NULL (NULL = still out)

fine

  • fine_id INT
  • loan_id → loan, UNIQUE
  • amount DECIMAL(8,2)
  • paid BOOLEAN DEFAULT FALSE
  • paid_on DATE NULL

Relationships

  • category 1 : N book · publisher 1 : N book
  • book M : N author, through book_author
  • member 1 : N loan · book 1 : N loan · staff 1 : N loan (loan is the bridge between member and book)
  • loan 1 : 0..1 fine (a fine exists only for a late return)

Available copies (calculated, never stored)

available = book.total_copies
          - (SELECT COUNT(*) FROM loan l
             WHERE l.book_id = book.book_id AND l.return_date IS NULL)

Business rules (example values)

  • Loan period 14 days estimate
  • Max 3 active loans per member estimate
  • Late fine ₹5 per day estimate. Use your college library's real rules if you know them.

SQL deliverables (sam)

Order of work: tables + data → triggers + procedures (to kiran by about 1 pm Sun) → views → queries.

2 triggers

  • trg_before_loan_insert (BEFORE INSERT on loan): count the book's open loans. If that count ≥ total_copies, reject with SIGNAL SQLSTATE '45000' "No copies available". Do the same if the member already has 3 open loans: "Borrow limit reached".
  • trg_after_loan_return (AFTER UPDATE on loan): writes the fine only. It changes no other table. 
    IF OLD.return_date IS NULL AND NEW.return_date IS NOT NULL
   AND NEW.return_date > NEW.due_date THEN
  INSERT INTO fine (loan_id, amount)
  VALUES (NEW.loan_id, DATEDIFF(NEW.return_date, NEW.due_date) * 5);
END IF;
    The OLD.return_date IS NULL guard stops a second fine (which would fail on fine.loan_id UNIQUE) when someone edits a loan that's already returned.

2 procedures

  • sp_issue_book(member_id, book_id, staff_id): insert the loan with issue_date = CURDATE() and due_date = CURDATE() + INTERVAL 14 DAY. The trigger does the checks.
  • sp_return_book(loan_id): UPDATE loan SET return_date = CURDATE() WHERE loan_id = … AND return_date IS NULL, then return the fine (if any)

2 views

  • v_book_catalog: book + authors (GROUP_CONCAT) + category + publisher + available copies (calculated as above)
  • v_active_loans: open loans with member, book, due date and days overdue

Reading and writing with Streamlit

import streamlit as st
from sqlalchemy import text

conn = st.connection("mysql", type="sql")   # settings in .streamlit/secrets.toml

# read (ttl=0 so lists refresh right after a write)
books = conn.query("SELECT * FROM v_book_catalog", ttl=0)

# write: call a procedure, show the trigger's SIGNAL message on failure
try:
    with conn.session as s:
        s.execute(text("CALL sp_issue_book(:m, :b, :st)"),
                  {"m": member_id, "b": book_id, "st": staff_id})
        s.commit()
    st.success("Book issued")
except Exception as e:
    st.error(f"Could not issue: {getattr(e, 'orig', e)}")

st.connection needs Streamlit 1.28+. Don't commit secrets.toml.
